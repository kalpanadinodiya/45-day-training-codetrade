# E-Commerce Sales Performance Analysis Report

## Introduction

This project focuses on analyzing e-commerce sales performance using Exploratory Data Analysis (EDA). The objective was to understand sales trends, identify high revenue-generating product categories, and derive meaningful business insights from the dataset.

## Dataset Used

The project used the Brazilian E-Commerce Public Dataset (Olist Dataset), which contains information about:

* Orders
* Products
* Product Categories
* Revenue Details

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

### 1. Data Loading

Multiple CSV datasets were loaded into Pandas DataFrames.

### 2. Data Cleaning

Missing values were identified and removed to improve data quality.

### 3. Data Merging

Datasets were merged using common columns such as product_id and product_category_name.

### 4. Exploratory Data Analysis

EDA techniques were used to analyze:

* Revenue distribution
* Product category performance
* Correlation between variables

### 5. Data Visualization

Bar charts, histograms, and heatmaps were created for better understanding of the data.

## Key Findings

1. Certain product categories generated significantly higher revenue.
2. Revenue distribution showed variation across products.
3. Correlation analysis helped identify relationships between price, freight value, and revenue.
4. Data visualization improved understanding of customer purchasing trends.

## Conclusion

The project successfully demonstrated how Exploratory Data Analysis can help businesses understand sales performance and make data-driven decisions. The analysis highlighted important revenue trends and business opportunities within the e-commerce dataset.
